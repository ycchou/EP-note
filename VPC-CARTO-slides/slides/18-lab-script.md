# 你在 Lab 裡可以直接講的版本

<div class="subtitle">VPC CARTO Workflow 口語版</div>

Note:
這是 Workflow Part 15。把所有理論濃縮成 lab 裡 5 秒可以講完的口頭版。

---

## VPC CARTO Workflow · 口語版（一）

```text
這個 VPC case 我們先用 Auto Pattern Bank 觀察病人有幾種 PVC morphology，

接著用 Pattern Matching 選定 clinical PVC 作為 target，

避免 activation map 混入不同 PVC。
```

<div class="callout">
<span class="label">情境</span>
Operator 對主治：「我們先 baseline 5 分鐘，等 APB 分類完，鎖定 target 再開始 mapping。」
</div>

---

## 口語版（二）

```text
target morphology 確認後，我們建立懷疑 chamber 的 anatomy，

如果 PVC 頻繁，就用 LAT Hybrid 做 activation mapping，

找 local EGM 比 QRS onset 最早的位置，

同時確認 unipolar 是否為 QS pattern。
```

<div class="callout gold">
<span class="label">情境</span>
Operator 引導 fellow：「這個點 –32 ms，unipolar QS，看起來不錯，等等再 PASO confirm。」
</div>

---

## 口語版（三）

```text
找到 earliest site 後，再用 PASO 做 pace mapping，

比較 paced QRS 跟 clinical PVC 的 similarity。

如果 earliest activation、unipolar QS、PASO 高分且 anatomy 安全，

就可以作為 ablation target。
```

<div class="callout red">
<span class="label">情境</span>
Operator pre-RF checklist：「LAT –35 ms、PASO 94%、anatomy 在 RVOT septal、distance to coronary OK，可以下 RF。」
</div>

---

## 口語版（四）

```text
ablation 後再用 Pattern Matching 確認 target PVC 是否消失，

並用 Auto Pattern Bank 判斷是否出現新的 PVC morphology。
```

<div class="callout">
<span class="label">情境</span>
Operator post-RF：「Target morphology 過去 25 分鐘 0 顆，iso 加到 5 mcg 也 0 顆，APB 也沒看到新型 — 我們 wrap up。」
</div>

# Pre-case Preparation

<div class="subtitle">術前 — 從 12-lead EKG 預判 origin</div>

Note:
這是 Workflow Part 1。進 lab 前一定要先看 VPC morphology，這決定後續所有 setup。

---

## 12-lead EKG 預判 origin

進 lab 前先看 VPC morphology：

| 12-lead finding | 可能 origin |
| --- | --- |
| LBBB + inferior axis + late transition | **RVOT** |
| LBBB / inferior + early transition | **LVOT / aortic cusp** |
| Inferior axis + lead I negative + early transition | **LV summit / LCC** |
| RBBB + superior axis | LV inferior / **fascicular** / **papillary muscle** |
| LBBB + superior axis | RV apex / inferior RV |
| Narrow septal PVC | **Para-Hisian** |

Note:
這張表是預判 origin 的快速 reference。VPC 進 lab 前看完這張表，就大致知道要準備哪些 catheter、哪些 chamber 要 map。

---

## 預判的目的 · 不是 100% 定位

這一步的目的不是要 100% 定位，而是決定：

</div>

<div class="desc">LV summit 可能來源</div>
</div>

<div class="num">5</div>

<div class="desc">His、coronary artery、valve、papillary muscle</div>
</div>
</div>

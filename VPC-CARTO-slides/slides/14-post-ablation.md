# Post-ablation Validation

<div class="subtitle">怎麼確認 case 真的成功？</div>

Note:
這是 Workflow Part 11。RF 結束不等於 case 結束 — 還要等、誘發、確認。

---

## Step 1 · 觀察 Spontaneous PVC

```text
等待至少 20–30 分鐘
```

看 target PVC 是否消失。

<div class="callout">
<span class="label">為什麼要等</span>
RF lesion 形成需要時間；某些 PVC 在 lesion 完成前還會出現。20–30 分鐘是<strong>業界最低標準</strong>。
</div>

Note:
急著拔 catheter 是新人最常見的錯 — 等不夠時間，redo 率會明顯上升。

---

## Step 2 · 誘發

| 方法 | 目的 |
| --- | --- |
| **Isoproterenol** | 誘發 catecholamine-sensitive PVC |
| Burst pacing | 誘發 ventricular ectopy |
| Programmed stimulation | 視情況 |
| 停止 sedation 刺激 | 有些 PVC sedation 下會消失 |

<div class="callout red">
<span class="label">Iso 必做</span>
很多 PVC 是 catecholamine-sensitive，sedation 下不出現。Iso 是這類 case 的最終驗證手段。
</div>

Note:
Isoproterenol 通常從 1–3 mcg/min 起始，逐步加量到 HR ~ 120 bpm，觀察 5 分鐘。

---

## Step 3 · 用 Pattern Matching / Auto Pattern Bank 確認

這時候模組又很重要。

<div class="cols">
<div>

### Pattern Matching
確認：

```text
原本 target VPC 是否真的沒有再出現。
```

</div>
<div>

### Auto Pattern Bank
確認：

```text
術後出現的是不是同一 morphology？
還是新的 VPC morphology？
```

</div>
</div>

Note:
這是 Pattern Matching 與 APB 在 case 尾聲的重要角色 — 它們不只 baseline 用，post-ablation 也要用。

---

## 術後判斷

| 術後情況 | 解讀 |
| --- | --- |
| **target morphology 完全消失** | **acute success** |
| 原 morphology 不見，但新 morphology 出現 | 可能多 focus |
| 同 morphology 低頻復發 | **lesion 不完整或 edema temporary effect** |
| morphology 稍微改變 | **exit 改變，origin 可能仍存在** |

<div class="callout gold">
<span class="label">判讀關鍵</span>
「morphology 稍微改變」是最容易誤判的情況 — 看起來像新 VPC，其實是原 origin 換 exit 了，要重新 map。
</div>

Note:
這四種情況決定你要不要繼續燒、要不要結束 case、要不要 schedule redo。

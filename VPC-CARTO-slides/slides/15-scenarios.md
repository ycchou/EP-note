# 臨床情境 · Scenarios

<div class="subtitle">4 種典型 case 的完整 workflow</div>

Note:
這是 Workflow Part 12。前面所有理論集合起來，套用到 4 個典型情境。

---

## Scenario 1 · Frequent Monomorphic RVOT PVC

### Workflow

```text
1. Pattern Matching 建 target PVC template
2. Auto Pattern Bank 確認主要只有一種 morphology
3. 建 RV / RVOT anatomy
4. LAT Hybrid 收 activation points
5. 找 earliest site
6. 看 unipolar QS
7. PASO confirm
8. RF ablation
9. Pattern Matching 確認 target PVC 消失
```

<div class="callout">
<span class="label">重點</span>
這種最適合 <strong>activation mapping</strong>。<br/>
也是新人最常見、最容易學會的入門 case。
</div>

Note:
Scenario 1 是經典中的經典 — 走完這個 workflow，後面所有 scenario 都是變體。

---

## Scenario 2 · Infrequent PVC

### Workflow

```text
1. Pattern Matching 建 target
2. Auto Pattern Bank 收集所有 morphology
3. 建完整 suspected chamber anatomy
4. 等 PVC 出現時用 LAT Hybrid 收點
5. 若點不夠，用 PASO 主導
6. 高 PASO 區域再等 PVC 確認 activation
7. RF
8. Isoproterenol 誘發驗證
```

<div class="callout red">
<span class="label">重點</span>
PVC 少的時候，<strong>不要硬做不完整 activation map</strong>。<br/>
此時 <strong>PASO + EKG prediction + anatomy safety</strong> 會變得更重要。
</div>

Note:
新人常犯的錯：PVC 一小時只來 5 顆，還執著於收 LAT — 應該果斷切換到 PASO 主導。

---

## Scenario 3 · Multiple PVC Morphologies

### Workflow

```text
1. Auto Pattern Bank 先分類
2. 對照術前 Holter / 12-lead 決定 clinical PVC
3. Pattern Matching 鎖定 target morphology
4. 只 map target PVC
5. Ablation 後重新看 Pattern Bank
6. 若主要 morphology 消失，再決定是否處理第二 morphology
```

<div class="callout">
<span class="label">重點</span>
<strong>不要把不同 morphology 混在同一張 LAT map</strong>。<br/>
APB 是這類 case 的靈魂模組。
</div>

Note:
這是「sequential ablation」的概念 — 一型一型處理，不要一次貪。

---

## Scenario 4 · Suspected LV Summit PVC

### Workflow

```text
1. Pattern Matching 鎖定 target
2. Auto Pattern Bank 確認 morphology
3. 建 LVOT / aortic cusp / RVOT / CS anatomy
4. LAT Hybrid 分別比較各 chamber earliest timing
5. PASO 比較 LCC、RCC、LV endocardium、RVOT、GCV / AIV
6. 若 CS / GCV / AIV early，要確認 coronary distance
7. 選最安全、最早、PASO 最佳位置 ablate
```

<div class="callout red">
<span class="label">重點</span>
LV summit <strong>不要只看一個 chamber</strong>。
常常需要比較：<br/>
<code>RVOT vs LVOT vs cusp vs coronary venous system</code>
</div>

Note:
LV summit 是 CARTO 3 mapping 最展現價值的 case — 因為可以多 chamber 並列比較 timing。

---

## Scenario 5 · Papillary Muscle PVC

### Workflow

```text
1. Pattern Matching 確認 target PVC
2. 建 LV anatomy
3. ICE 建 papillary muscle anatomy
4. LAT Hybrid 找 earliest papillary region
5. PASO 輔助，但分數可能不穩
6. 重點看 catheter stability / contact
7. RF lesion 可能需要多點
8. 術後用 Pattern Matching 確認 morphology 消失
```

<div class="callout gold">
<span class="label">重點</span>
Papillary muscle case：<br/>
PASO 可能受 <strong>catheter orientation 和 capture area</strong> 影響。<br/>
<strong>ICE + contact stability 很重要。</strong>
</div>

Note:
Papillary case 的 PASO 不穩是常態 — 不要因為 PASO 89% 就放棄好點；要看 LAT 與 ICE catheter contact。

---

## Scenario 6 · Para-Hisian PVC

### Workflow

```text
1. Pattern Matching 鎖定 target
2. 建 RA septum / RV septum / His region / NCC anatomy
3. 標記 His potential
4. LAT Hybrid 找 earliest
5. 若 His 附近最早，務必評估 NCC 或 opposite side 是否也 early
6. PASO 輔助
7. 低功率、短時間、小心 AV conduction
8. 嚴密監測 PR / AH / HV
```

<div class="callout red">
<span class="label">重點</span>
Para-Hisian case <strong>不是找到最早就直接燒</strong>。<br/>
要先問：<br/>
<code>有沒有 safer site？例如 NCC、RV septum opposite site、LV septum？</code>
</div>

Note:
Para-Hisian 的精髓在於「即便找到 origin，也要找替代位置燒」 — safety > timing。

---

## 🎯 Scenarios · 一張表看完

| Scenario | 主力模組 | 關鍵注意 |
| --- | --- | --- |
| 1 · RVOT frequent | LAT Hybrid | 教科書 case |
| 2 · Infrequent | **PASO** | 別硬做 LAT |
| 3 · Multi-morphology | **APB** | 一型一型處理 |
| 4 · LV summit | LAT + PASO multi-chamber | 比較多 chamber |
| 5 · Papillary muscle | **ICE** + LAT | Stability 第一 |
| 6 · Para-Hisian | LAT + safety map | 找替代位置 |

Note:
每個 scenario 都有自己的「主角模組」 — 用對工具，case 才會順。
